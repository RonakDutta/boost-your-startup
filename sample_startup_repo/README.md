# CampusEats (demo repo for the Failure Simulator)

A small, made-up backend for a campus food-ordering startup. It is written the way
early startup code often is, so the Failure Simulator has real failure points to
find: network calls without a timeout, errors that are silently ignored, an SQL
query built from user text, a key written into the code, and similar. Nothing
here is run by the Co-Pilot; it is only read.
